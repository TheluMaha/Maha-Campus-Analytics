# Smart Maha Campus Analytics

## About the Project

Smart Maha Campus Analytics is a student data analytics project that I created to understand different aspects of a college campus.

In this project, I worked with student information such as academic marks, attendance, internships, placements, skills, projects, departments, and companies.

I used Excel and SQL for working with the data and Power BI to create an interactive dashboard.

## What I Wanted to Find

The main purpose of this project was to understand the student data and find useful information from it.

Some of the things I wanted to analyze were:

- How many students are there?
- How are students distributed across departments?
- What is the average CGPA?
- What is the average attendance?
- How are students performing in different subjects?
- How many students are placed?
- What is the placement percentage?
- Which companies have recruited students?
- What internship domains are available?
- What skills are common among students?

## Tools I Used

I used the following tools for this project:

- Excel – for working with and preparing the data
- SQL – for querying and analyzing the data
- Power BI – for creating the dashboard and visualizations

## Power BI Dashboard

I created a one-page Power BI dashboard called "MAHA CAMPUS ANALYTICS".

The dashboard contains:

- Total Students
- Average CGPA
- Average Attendance
- Placement Percentage
- Average Package
- Students by Department
- Average Marks by Subject
- Placement Status
- Internship Domain
- Average Attendance by Department
- Company-wise Placements
- Skill Distribution
- Student Details

The dashboard also has slicers for Department, Year, Placement Status, Subject, and Internship Domain.

These slicers allow the user to select different options and see the dashboard change according to the selection.

## Dataset

The dataset contains information related to students and different areas of campus life.

The main data includes:

- Student details
- Department details
- Academic performance
- Attendance
- Internships
- Placements
- Projects
- Skills
- Student skills

## Dataset Note

The data used in this project is synthetic data created for learning and portfolio purposes.

It is not real college data and does not contain actual student records.
